# Algoritmos e Programação: Microatividades e Calculadora em Python

Disciplina **DGT2817 - Lógica, Algoritmos e Programação de Computadores**.

Este repositório reúne as microatividades de **estruturas de decisão**, **estruturas de repetição** e **funções** em Python, além do Trabalho Final: uma **calculadora** que combina esses conceitos com modularização.

## Arquivos do projeto

| Arquivo | Finalidade |
|---|---|
| `estruturas_condicao1.py` | Microatividade 1 de estruturas de decisão |
| `estruturas_condicao2.py` | Microatividade 2 de estruturas de decisão |
| `estruturas_repeticao1.py` | Microatividade 1 de estruturas de repetição |
| `estruturas_repeticao2.py` | Microatividade 2 de estruturas de repetição |
| `funcoes1.py` | Microatividade 1 de funções |
| `funcoes2.py` | Microatividade 2 de funções |
| `calculadora_v2.py` | Trabalho Final: calculadora modularizada |

## Conteúdos praticados

### Estruturas de decisão

- Uso de `if`, `elif` e `else`.
- Operadores de comparação e lógicos.
- Tomada de decisão a partir de dados informados pelo usuário.

### Estruturas de repetição

- Laços `for` e `while`.
- Controle do fluxo com `break` e `continue`.
- Repetição de operações até que uma condição seja atendida.

### Funções

- Definição de funções com `def`.
- Parâmetros e valores de retorno.
- Reaproveitamento de código.

## Trabalho Final: calculadora

O arquivo `calculadora_v2.py` integra os três conteúdos em um único programa:

- **Decisão:** escolha da operação a ser realizada.
- **Repetição:** execução de novos cálculos sem reiniciar o programa.
- **Funções:** cada operação organizada em sua própria função.
- **Modularização:** código dividido em partes pequenas e fáceis de manter.

## Como executar

1. Instale o Python 3.
2. Abra o terminal na pasta do projeto.
3. Execute o script desejado:
bash python calculadora_v2.py

No Windows, também é possível usar `py .\calculadora_v2.py`. Os demais arquivos rodam do mesmo modo, trocando o nome do script.
